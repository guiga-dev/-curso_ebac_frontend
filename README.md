# Exercício módulo 19 — Boas práticas de CSS

Refatoração do material fornecido pela EBAC usando BEM em CSS puro.
Abra `index.html` para visualizar; não há dependências ou compilação.

| Papel | Classe |
| --- | --- |
| Bloco de listagem | `produtos` |
| Bloco de produto | `produto` |
| Elementos do produto | `produto__imagem`, `produto__nome`, `produto__descricao` |
| Modificador de destaque | `produto--destaque` |

O modificador é usado junto da classe base: `produto produto--destaque`.
As classes foram renomeadas de forma correspondente no HTML e CSS. Conteúdo,
estrutura, seletores de bloco e todas as propriedades e valores CSS foram mantidos.
