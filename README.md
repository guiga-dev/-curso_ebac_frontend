# Exercício módulo 26 — TypeScript

Duas funções com argumentos e retornos tipados:

- `multiplicar(a: number, b: number): number` retorna o produto.
- `saudar(nome: string): string` retorna `Olá ` concatenado com o nome.

```sh
npm ci
npm run build
npm start
```

O modo `strict` está habilitado e o compilador não emite JavaScript quando há
erros de tipo. O código TypeScript está em `index.ts` e o compilado em `dist`.
