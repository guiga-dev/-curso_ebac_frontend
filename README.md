# Exercício módulo 25 — ES6+

`alunos.js` define um array de objetos com `nome` e `nota` e a função
`filtrarAprovados`, que retorna apenas alunos com nota maior ou igual a 6.
Usa `const`, arrow function, desestruturação e `Array.prototype.filter`.
O array original não é modificado.

Execute `node alunos.js`. Resultado: Ana (9.5), Carla (6) e Elisa (8).
